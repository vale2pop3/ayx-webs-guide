# ayx-webs-guide

本仓库用于归档和发布多个独立 HTML 页面，作为通用网页资源的集合与索引。

## 项目简介

`ayx-webs-guide` 是一个静态页面归档仓库，主要存放各类独立实现的 HTML 文件。这些页面不针对特定网站或域名，而是作为通用参考、示例或工具页面使用。仓库采用纯前端技术栈，无需后端支持，可直接通过 GitHub Pages 或其他静态托管服务访问。

## 目录结构

```
ayx-webs-guide/
├── pages/          # 存放所有 HTML 页面文件
├── assets/         # 公共资源（如有）
│   ├── css/        # 样式文件
│   ├── js/         # 脚本文件
│   └── images/     # 图片资源
├── index.html      # 仓库入口页 / 页面索引
└── README.md       # 本文件
```

- `pages/`：核心目录，每个子文件夹或文件对应一个独立的 HTML 页面。
- `assets/`：可选，存放页面间共享的静态资源。
- `index.html`：通常作为导航页，列出所有归档页面的链接。

## 页面归档说明

- 所有页面均为独立的 HTML 文件，可直接在浏览器中打开运行。
- 页面功能涵盖各类常见场景，如信息展示、工具模拟、布局演示等。
- 每个页面尽量保持自包含，减少对外部资源的依赖。
- 归档页面可能不定期更新或补充，不保证所有页面长期可用或功能完整。

## 维护说明

- 欢迎提交 Issue 或 Pull Request 以修正错误、改进页面或添加新内容。
- 新增页面请放入 `pages/` 目录，并更新 `index.html` 中的索引链接。
- 请保持页面代码简洁、清晰，避免引入过多外部依赖或复杂逻辑。
- 本仓库不收集用户信息，不包含任何跟踪代码或第三方服务。

## 使用方式

1. 克隆或下载本仓库到本地。
2. 直接在浏览器中打开 `index.html` 或 `pages/` 下的任意页面。
3. 也可通过 GitHub Pages 等静态托管服务部署后在线访问。
